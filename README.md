# DataPilot AI

DataPilot AI is an autonomous dataset automation platform designed to understand, validate, clean, analyze, visualize, model, and report on structured datasets.

## Current Status

Phase 1 — Foundation

### Implemented

- Python virtual environment
- Project architecture
- Configuration management
- Environment variable management
- Application logging
- File utilities
- Dataset validation
- CSV/XLSX/XLS/JSON loading foundation
- FastAPI backend
- Streamlit frontend
- Automated test suite

## Tech Stack

- Python
- FastAPI
- Streamlit
- Pandas
- NumPy
- Pydantic
- Pytest
